# MyAI-Brain

A personal knowledge app built with NestJS, PostgreSQL, Qdrant, and Gemini.

It creates notes from YouTube videos, saves manual notes, and finds similar notes.

**[Open the working prototype](https://217-154-194-93.sslip.io)**

Access is available on request. The prototype requires a username and password.
